🌙 睡眠守护 · 用户说明书

一、软件概述

睡眠守护是一款面向大学生群体的作息健康管理工具，由 Stack Overflow 小组（王晨瑜、董弈齐、曾梓航）开发。github 链接请点击此处。它帮助您记录并回顾每日作息、生成健康评分与趣味称号，并提供周报分析、睡眠图表分析、键盘注意力监测、自定义设置和数据清除等等进阶功能。

二、安装与运行

    如果基于qt project构建

  • 编译环境 ：Qt 6.5+，CMake 3.19+，C++17 编译器
  • 构建步骤 ： cmake -B build && cmake --build build

    • 如果基于release的压缩包

  • 解压后点击.exe文件即可运行

    • macOS 权限 ：键盘监测功能需要授予「输入监控」权限（系统设置 → 隐私与安全性 → 输入监控）

三、界面导览

  • 📅 日历 ：点击任意日期查看历史作息，不同颜色标记当日状态，具体规则见下
  • 🛌 打卡区 ：「准备入睡」和「我醒了」两大核心按钮，以及“我熬穿了”按钮一键实现熬大夜
  • 📊 数据区 ：午睡/运动/久坐输入框、周报分析面板与图表统计面板
  • 🔧 工具栏 ：自定义设置、键盘监测、数据清理、帮助（?）
颜色 含义
红 通宵熬夜，整夜未眠
紫 睡懒觉（起床晚于设定的一般起床时间两小时及以上）
橙 睡眠评分1分：睡眠小于6h或大于10h
蓝 睡眠评分2分：睡眠6-7h或9-10h
绿 睡眠评分3分（最高）：睡眠7-9h

四、每日打卡流程

基础用法：
  1. 晚上准备睡觉时，点击 「准备入睡」 按钮，系统自动记录并保存当前时间为入睡时间
  2. 填写午睡时长、运动时长、久坐时长等白天数据，空着也没有关系
  3. 第二天早上醒来，点击 「我醒了」 按钮，系统记录并保存起床时间
  4. 如果醒来之后有什么想记下来的，可以写在「睡眠日记」这个文字框里！
  5. 在弹出的确认框中，核对入睡/起床时间是否准确
  6. 核对完成后点击确认，将保存当天记录的所有数据到本地 JSON 文件
注意「睡眠日记」里的数据也是保存在数据文件中的哦，所以写完别马上切走

悬浮窗用法： 3.1版本加入了悬浮窗，在程序运行（前台/后台）时，悬浮窗将始终悬浮于桌面上，点击后会出现「准备入睡」和「我醒了」两个按钮，和主窗口的按钮是等价的，方便大家使用！

五、手动编辑与补录

点击日历上 过去的日期 ，右侧会显示该日已经保存的数据。「修改入睡时间」和「修改起床时间」以及「保存并生成简报」按钮变为可用，前两个按钮点击后可在弹窗中精确调整时间。

点击 「保存并生成简报」 按钮后，将保存目前已记录的数据并生成当日简报

如果某天通宵未睡，可点击 「我熬穿了」 按钮进行标记，然后再保存当日数据。

六、周报分析及导出

点击 「周报生成」 按钮，系统会读取 （包含）当前选中日期 向前数近 7 天数据能读取的所有数据进行综合分析：

  • 本地模式 ：无需网络，调用内置算法生成文字周报
  • AI 模式 ：在输入框中填入 DeepSeek API Key（以 sk- 开头），系统将数据发送给大模型，生成宗门大长老毒舌修仙风格的分析报告
    • 如果API无法正常使用，则会报错并调用本地模式。
周报生成后，可以点击「导出PDF」按钮，导出周报PDF到指定位置。

七、图表可视化

点击 「图表」 按钮，弹出可视化窗口：

  • 📊 睡眠时长柱状图 ：展示近 7 天每日睡眠时长（含午睡叠加），附带 7-8 小时推荐参考线
  • 📈 评分趋势折线图 ：展示每日睡眠评分（-5 ~ 3）的变化趋势

八、键盘活跃度监测

点击 「键盘」 按钮打开键盘活跃度分析窗口。程序在后台实时记录每分钟敲击次数，生成注意力曲线柱状图。

数据在打开程序至少一分钟之后才开始生成柱状图，保留最近 8 小时， 绿色=低活跃 ， 黄色=中活跃 ， 红色=高活跃 。

九、系统托盘与通知

  • 点击窗口关闭按钮会 最小化到系统托盘 而非退出程序
  • 托盘图标右键可「显示主窗口」或「退出程序」
  • 在自定义的熬夜区间期间（默认是0:01-8:00）未记录入睡，系统会自动弹出 深夜提醒 气泡通知
  • 点击 「设置」 可调整常规入睡/起床时间、熬夜判定区间

十、自定义设置

在自定义设置界面，可以设置四个参数：
  • 一般入睡时间
  • 一般起床时间
  • 熬夜判断起始时间
  • 熬夜判断结束时间
这些参数用于判断是否早睡早起、是否睡懒觉、是否熬夜等，适用于作息时间段不同的同学，但用于评价睡眠分的睡眠时长（例如7-9h）不可自定义。

十一、数据管理

  • 清空当前日期 ：删除日历上选中那天的数据
  • 清空指定区间 ：选择起始和结束日期，批量删除
  • 清空全部数据 ：一键重置所有作息记录
  • 数据以 JSON 格式存储在自动创建的系统应用数据目录下，实现了持久化

十二、成就系统

每次点击「我醒了」或「保存并生成简报」按钮后，会刷新成就的判定，从当前日期的前一天开始往前数最多三个月，只记最近的满足条件的日期段。
  • 连续打卡 7 天、30 天（存在数据文件）解锁规律作息勋章
  • 连续早睡（早于23:00，该时间不可调整） 3 天、7 天解锁早睡勋章
  • 连续 3 、 7 天睡眠分等于 3 ：优质睡眠
  • 连续 3 、 7 天睡眠分大于等于 2 但不完全为 3 ：不错的尝试
达成成就时弹出提示并播放音效，当前最新达成的成就会显示在主窗口上端

十三、窗口自布局

主窗口的大小可以随意放大缩小，窗口组件的位置会根据窗口大小自动布局到合适的位置。

十四、常见问题

Q：如何彻底关闭程序？
A：有两种方式：

  • 在以任意方式打开的说明书页面，点击 退出程序
  • 在程序最小化到托盘后，点击托盘图表，在弹出的选项框里点击 关闭程序
程序不会开机自启，每次关机后请重新打开

Q：为什么键盘监测没有反应？
A：macOS 需要在「系统设置 → 隐私与安全性 → 输入监控」中授予权限。以及可能还没有到数据记录的一分钟时间下限。

Q：为什么 AI 周报告失败？
A：请检查 API Key 是否以 sk- 开头且余额充足，网络请求有 15 秒超时限制。

Q：数据存在哪里？
A：存储在系统应用数据目录（ QStandardPaths::AppDataLocation ）下的 .json 文件中，以日期命名。

Q：有的数据没有填写好，其他数据也能保存吗
A：可以。入睡和起床时间二者只要任意一个一旦记录，或者点击「保存并生成简报」的按钮，就会保存当日数据，暂时没有记录的数据会以特殊方式记录在JSON文件中。

Q：我不小心提早点了「准备入睡」或者「我起床了」按钮，或者忘了点「我起床了」按钮，怎么办？
A：没有关系，等到你真的要入睡时再按一遍「准备入睡」按钮，就能覆盖之前的入睡时间数据。起床时间的重新设置，可以在起床按钮已经点击后，在日历上选中昨天，用手动修改功能就可以修改昨天的起床时间了（如果你起床时已经是入睡后的第二天了）

Q：「保存并生成简报」按钮和「我起床了」按钮有什么区别？
A：这两个按钮原本是单独实现的，但后面发现它们的功能几乎完全一样，就是保存数据并生成简报。唯一的区别在于「我起床了」需要记录点击按钮时的实时时间，「保存并生成简报」按钮只需读取起床时间框的里的时间，与实时时间无关。现在「我起床了」按钮内部调用了「保存并生成简报」被点击的实现。

Q：我睡到第二天起床后，日历上选择的日期已经是第二天了，不是入睡的那一天了，那这样的话我点击「我起床了」按钮，数据会保存到哪里去呢？
A：不用担心，「我起床了」按钮中会调用「保存并生成简报」，在这个实现中关于日期变化，我们设计了“作息日”概念。“作息日”根据入睡的时间及所在的日期确定。

  • 如果入睡时间在24点前，则作息日为入睡时间所在日期；
  • 如果入睡时间在24点后，【自己设定的熬夜结束区间】前，则作息日为入睡时间前一天的日期。
  • 如果入睡时间在【自己设定的熬夜结束区间】后，那你岂不是应该点通宵喽。
作息日的入睡时间，当晚睡眠的起床时间，以及作息日当天的白天数据，都保存在作息日的数据文件中。无论是记录当天作息，还是手动选中了以前的日期并点击「保存并生成简报」按钮，这套逻辑都是适用的。

Q：为什么我的日历上看起来已经满足了达成成就所需的条件，但是并没有给我颁发成就，即使重新保存记录刷新成就也没有？
A：因为只有在刚好达到成就所需天数的那天，才会触发成就颁发，因此靠后来填补数据很难达到颁发成就所需的条件。因此记得每天及时打卡！

Q：这个程序的内存占用大吗？
A：这是一个轻量级的应用，内存占用很小。在笔者（曾梓航）的电脑（Lenovo Thinkbook 14 G7+ IAH，intel CORE Ultra 7,32G）上，应用在前台时测得的最大内存占用为55.4MB，应用最小化到托盘后测得的最大内存占用为52.8MB。虽然程序包含一个每分钟自动刷新的功能，但是这点频率占用对CPU单核主频来说都可以忽略不计。
