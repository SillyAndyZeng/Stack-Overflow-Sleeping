🌙 睡眠守护 · 用户说明书

一、软件概述

睡眠守护是一款面向大学生群体的作息健康管理工具，由 Stack Overflow 小组（王晨瑜、董弈齐、曾梓航）开发。它帮助您记录每日作息、生成健康评分与趣味称号，并提供周报分析、键盘注意力监测等进阶功能。

二、安装与运行

  • 编译环境：Qt 6.5+，CMake 3.19+，C++17 编译器
  • 构建步骤：cmake -B build && cmake --build build
  • macOS 权限：键盘监测功能需要授予「输入监控」权限（系统设置 → 隐私与安全性 → 输入监控）

三、界面导览

  • 📅 左侧日历：点击任意日期查看历史作息，不同颜色标记当日状态
  • 🛌 中部打卡区：「准备入睡」和「我醒了」两大核心按钮
  • 📊 右侧数据区：午睡/运动/久坐输入框、周报与 AI 分析面板
  • 🔧 顶部工具栏：设置、键盘监测、数据清理、帮助（?）

四、每日打卡流程

  1. 晚上准备睡觉时，点击「准备入睡」按钮，系统自动记录当前时间为入睡时间
  2. 第二天早上醒来，点击「我醒了」按钮，系统记录起床时间
  3. 在弹出的确认框中，核对入睡/起床时间是否准确
  4. 填写午睡时长、运动时长、久坐时长等白天数据
  5. 点击「保存并生成简报」，系统自动计算睡眠评分并弹出日结报告

五、手动编辑与补录

点击日历上过去的日期，右侧会显示该日数据。「修改入睡时间」和「修改起床时间」按钮变为可用，点击后可在弹窗中精确调整时间。

如果某天通宵未睡，可点击「通宵」按钮进行标记。

六、周报与 AI 分析

点击「周报生成」按钮，系统会读取近 7 天数据进行综合分析：

  • 本地模式：无需网络，调用内置算法生成文字周报
  • AI 模式：在输入框中填入 DeepSeek API Key（以 sk- 开头），系统将数据发送给大模型，生成毒舌修仙风格的分析报告

七、图表可视化

点击「图表」按钮，弹出可视化窗口：

  • 📊 睡眠时长柱状图：展示近 7 天每日睡眠时长（含午睡叠加），附带 7-8 小时推荐参考线
  • 📈 评分趋势折线图：展示每日睡眠评分（-5 ~ 3）的变化趋势

八、键盘活跃度监测

点击「键盘」按钮打开键盘活跃度分析窗口。程序在后台实时记录每分钟敲击次数，生成注意力曲线柱状图。数据保留最近 8 小时，绿色=低活跃，黄色=中活跃，红色=高活跃。

九、系统托盘与通知

  • 点击窗口关闭按钮会最小化到系统托盘而非退出程序
  • 托盘图标右键可「显示主窗口」或「退出程序」
  • 凌晨 2:00 ~ 6:00 期间未记录入睡，系统会自动弹出深夜提醒气泡通知
  • 点击「设置」可调整常规入睡/起床时间、熬夜判定区间

十、日历颜色说明

颜色含义
红通宵熬夜，整夜未眠
紫睡懒觉（起床晚于设定的一般起床时间两小时及以上）
橙睡眠评分1分：睡眠小于6h或大于10h
蓝睡眠评分2分：睡眠6-7h或9-10h
绿睡眠评分3分（最高）：睡眠7-9h

十一、数据管理

  • 清空当前日期：删除日历上选中那天的数据
  • 清空指定区间：选择起始和结束日期，批量删除
  • 清空全部数据：一键重置所有作息记录
  • 数据以 JSON 格式存储在系统应用数据目录下

十二、成就系统

  • 连续打卡 7 天、30 天解锁规律作息勋章
  • 连续早睡 3 天、7 天解锁早睡勋章
  • 达成成就时弹出提示并播放音效

十三、常见问题

Q：为什么键盘监测没有反应？
A：macOS 需要在「系统设置 → 隐私与安全性 → 输入监控」中授予权限。

Q：为什么 AI 周报告失败？
A：请检查 API Key 是否以 sk- 开头且余额充足，网络请求有 15 秒超时限制。

Q：数据存在哪里？
A：存储在系统应用数据目录（QStandardPaths::AppDataLocation）下的 .json 文件中，以日期命名。
